## 5. Regras de Ouro de Execução

1. **⚠️ Regra do Chat Quente (Não apague se estiver negociando):**
   - Se você estiver trocando mensagens no chat da OLX com um comprador interessado, **NÃO execute o script naquele momento**. Excluir o anúncio encerra ou arquiva o anúncio para o comprador. Espere a conversa esfriar ou feche a negociação antes.
2. **🛡️ Segurança de Local (Entrega em mãos):**
   - Como definimos no script a entrega 100% pessoalmente em mãos (sem Garantia/Correios da OLX), marque sempre em **locais públicos e movimentados** (portaria de shopping, estação de metrô ou praça de alimentação).
   - Peça pagamento via **PIX na hora**, conferindo a confirmação no extrato do seu aplicativo bancário antes de entregar o aparelho.
3. **Comandos Práticos Rápidos:**
   ```powershell
   # Para verificar o saldo antes de rodar:
   python republicar_anuncio.py cotas

   # Para reupar o item do dia diretamente:
   python republicar_anuncio.py celular
   python republicar_anuncio.py ventilador
   python republicar_anuncio.py fone
   ```
